## ⚡ Quick Start (5 Minutes)

### Step 1: Set Up Google AdSense Account

1. Visit: https://adsense.google.com
2. Sign in with your Google account
3. Click "Sign up now"
4. Enter your website URL: `https://vinayakvind.github.io/travel-earnings-blog/`
5. Fill in your details and payment info
6. Google will approve within 24-48 hours
7. Once approved, copy your ad code from AdSense dashboard
8. Paste in STEP 2 below

### Step 2: Add Your AdSense Code

⚠️ **YOU NEED TO DO THIS:**

1. Open `index.html` file in this repository
2. Find these lines (around lines 145-151, etc):
```html
<div class="ad-slot">📢 Advertisement Space #1 - Paste your Google AdSense code here</div>
```

3. Replace with your AdSense code (from your AdSense dashboard):
```html
<!-- Paste your Google AdSense ad code here -->
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX"
     crossorigin="anonymous"></script>
<ins class="adsbygoogle"
     style="display:block"
     data-ad-client="ca-pub-XXXXXXXXXXXXXXXX"
     data-ad-slot="XXXXXXXXXX"
     data-ad-format="auto"
     data-full-width-responsive="true"></ins>
<script>
     (adsbygoogle = window.adsbygoogle || []).push({});
</script>
```

### Step 3: Update Affiliate Links

1. Open `index.html` file
2. Search for lines with `href="#affiliate-` (around lines 100-130)
3. Replace `#` with your actual affiliate links:

**Amazon Links Example:**
- Find: `href="#affiliate-backpack"`
- Replace with: `href="https://amazon.in/s?k=backpacks&tag=YOURID-21"`

**How to Get Affiliate Links:**
- Amazon: https://affiliate-program.amazon.in
- Flipkart: https://www.flipkart-partners.com
- RedBus: https://www.redbus.in/affiliate
- MakeMyTrip: https://affiliates.makemytrip.com
- Booking.com: https://partner.booking.com

### Step 4: Deploy to Live URL

**Option A: GitHub Pages (Current)**
- Your site is live at: `https://vinayakvind.github.io/travel-earnings-blog/`
- GitHub Pages automatically updates when you change files

**Option B: Netlify (Faster)**
1. Visit: https://app.netlify.com/drop
2. Drag & drop the `index.html` file
3. Get instant live URL
4. Updates automatically from GitHub

**Option C: Custom Domain**
1. Buy domain from GoDaddy, Namecheap (₹300-500/year)
2. Connect to GitHub Pages or Netlify
3. Update DNS settings (hosting provider will guide)
